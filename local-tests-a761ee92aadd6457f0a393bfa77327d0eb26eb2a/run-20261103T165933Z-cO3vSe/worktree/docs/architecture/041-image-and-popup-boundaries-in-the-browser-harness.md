## Image and popup boundaries in the browser harness

Independent no-arrow editor scenarios receive a transparent work-resolution
arrow mask from an explicit, current-map GET mock. Authored arrow/portal fixtures
continue to own their imagery; no general image or write fallback is introduced.
The cached PNG does not modify production server rendering or viewer responses.
New-window document navigation is mocked at browser-context scope and removed
after use; parent page routes remain responsible for the parent editor. The
inspection stub verifies URL/isolation behavior, not full target-page rendering.
