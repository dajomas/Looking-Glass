## Preservation and verification

[The split manifest](usage/manifest.json) records the source commit and Git blob,
ordered paths, byte counts and SHA-256 hashes. Concatenate its `files` entries
in order to reconstruct the exact original 80,085-byte UTF-8 guide, including
line endings and its final newline state. This index and the manifest are not
part of source reconstruction. Every content file is below 10,000 bytes.
The manifest describes the original snapshot, not later semantic edits.

Original relative links and fragments remain verbatim inside the section files.
Resolve them relative to the old `docs/usage.md` base until links are deliberately
rebased; relocation can otherwise change their meaning. Adjacent continuation
parts belong together. Heading-like examples inside code fences were not treated
as section boundaries.
