Checkpoints are not backups

Restoring rewinds play state, not authored content, notes or permissions. Review compatibility and effects before restoring. Image, wall geometry, boundary settings, fog configuration or authored passage changes can block restore. Map names and room-note edits are preserved.

Checkpoint history is local to this database, is not included in campaign ZIP backups, and is not pruned automatically. Keep full installation backups. An automatic safety checkpoint is saved transactionally before every successful restore.
